COMUNICAR UNA PISTA

¿Has detectado un incidente?

Puedes enviar una pista, una fuente o solicitar una corrección mediante el repositorio público. Recibir una comunicación no implica que vaya a publicarse: primero se contrasta con fuentes fiables y se aplica la metodología del observatorio.

Qué información ayuda

  • Nombre de la empresa, producto o servicio afectado.
  • Enlace a la fuente original o aviso oficial, si existe.
  • Fecha aproximada y países o usuarios potencialmente afectados.
  • Qué afirmación concreta debería verificarse o corregirse.

No publiques contraseñas, documentos de identidad, datos bancarios, datos personales de terceros ni información sensible.

Abrir comunicación en GitHub →

Las comunicaciones son públicas en GitHub. Si la información contiene datos sensibles, no la envíes por este canal.
